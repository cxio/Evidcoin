# Evidcoin 证信链

> #### 声明
>
> **Evidcoin** 的安全性建立在历史用户基数的分散性之上，而非密码学唯一性或经济不可塑性。
> 系统在百日扩张之后、达到 N 万活跃用户之前，应被视为受信启动期。
>
> 在受信启动期内，系统的安全性较弱，可能受到攻击或操纵。用户应谨慎参与，并做好风险管理。

Evidcoin 是一种基于区块链技术的通用信用载体，以三种基本信元（币金、凭信和存证）为基础，支持多种信用表达和转移方式。

Evidcoin 也指证信链本身，以及其运行的区块链网络。

> **命名：**
> 简写 EVC，证信金 / 证金 / e币
