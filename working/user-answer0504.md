# 架构决策（未决项）

## High（高风险）

- H-1 四层状态指纹树（UTXO/UTCO Root）节点组合算法
    1. UTXO/UTCO 是针对交易的未花费/未转移状态进行总结，因此年度按交易时间戳计算，取标准时间（UTC）年度。
    2. 每层节点按该组分层字节（[8], [13], [18]）值自然排序（0-255）。计算哈希树时，按此顺序填充相应的值：各节点无间串接后计算该组哈希，填充到父节点位置。末端叶子节点按交易ID排序（字典序）组合。
    3. 对于空分支，32字节进行全零填充。即除顶层年度（无限增长）外，每层必然有256个元素，每个元素对应一个子集。

- H-2 Stakes 精确定义仍为未决（OQ-018）
    - Stakes 的含义为币权（币量*币龄），单位：聪时 = 聪*小时。当它出现在区块头里时，表示该区块里所有交易的币权。因为这些交易的输出都是新的，起始时间为0时（币权为零），因此实际上这里的币权就仅对输入部分有意义：就是销毁的币权，也称为币权销毁。此时就是区块所有交易的币权销毁总值。
    - 区块头内的 Stakes 字段为 uint64 类型，溢出部分简单丢弃（即最大值 0xffff_ffff_ffff_ffff）。这只是一个统计值，不影响共识，对安全（如铸凭哈希计算）的影响应当也可以忽略。

- H-3 字段宽度集体未决
    - 区块头内的整数字段（Version, Height）为 uint32 类型（4字节）。
    - 交易头内：Version 为 uint16（2字节），Timestamp 为 int64（8字节，单位毫秒）。
    - 其它整数如果没有明确定义，默认都为变长整数类型（Varint 或 Uvarint）。


- M-6 区块大小上限 / 单区块最大交易数未明确
    - 区块大小限制是一个按时间适度增长的逻辑，应当设计一个限制函数，时间按高度折合计算。
