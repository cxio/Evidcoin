## 构建指引

分析每一种类型的指令时，都需要包含 `0.基本约束.md` 中的内容作为前置说明。

如果需要理解脚本的工作和设计原理，可参考 `../6.脚本系统.md` 文档。

如果想更准确地理解脚本的使用，`../examples/` 下有好几个案例。


### 禁用指令清单

本指令集功能较强，考虑安全性和稳定性，正式主网前期会临时禁用如下指令：

- `SCRIPT`：有额外的验证成本，且可能不太常用，前期暂时禁用。
- `VALUE`：获取某值指令。前期尚无明确的使用场景。
- `EVAL`：运行时新脚本执行。前期使用场景不明。
- `INOUT`：获取输入项源输出集数据。有额外验证成本且前期使用场景不明。

> **实现：**
> 以上指令仍需实现，它们会运行在 `testnet` 和 `devnet` 中。
