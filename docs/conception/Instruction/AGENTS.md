## 构建指引

分析每一种类型的指令时，都需要包含 `0.基本约束.md` 中的内容作为前置说明。

如果需要理解脚本的工作和设计原理，可参考 `../6.脚本系统.md` 文档。

如果想更准确地理解脚本的使用，`../examples/` 下有好几个案例。**注**：部分示例代码可能已经过时，仅供参考。


### 禁用指令清单

本指令集功能较强，考虑安全性和可靠性，前期会有一些指令被禁用：

- `SCRIPT`：脚本引用值指令。网络成本较高，且可能不太常用。
- `VALUE`：获取某值指令。前期尚无明确的使用场景。
- `CALL`：调用指令。应当完整实现，但出于安全性和使用场景不充分，前期暂时禁用。
- `EVAL`：求值指令。与 `CALL` 类似，前期暂时禁用。
- `SHELL`：外壳指令。前期暂不支持调用外部程序。
- `INOUT`：输入源的输出项集环境指令。需要增加网络查询，效益不高且用途不足。

**注意**：该临时禁用规则为最高优先级，覆盖其它地方对指令使用的允许约定。
