# DECISION-0009: 哈希树边界情况

## Status（状态）

Accepted

## Context（背景）

`docs/conception` 多处使用哈希树表达交易树、输入/输出树、附件片组树和状态指纹树，但未统一说明空树、单叶树和奇数叶树的根计算方式。

## Decision（决策）

哈希树边界规则如下：

| 场景 | 规则 |
|------|------|
| 空树 | 根为对应根类型长度的全零字节。 |
| 单叶树 | 根等于该叶子哈希本身，不再计算分支哈希。 |
| 奇数叶 | 复制最后一个叶子，与其自身配对后继续向上计算。 |

示例：

```text
[A, B, C] -> [A, B, C, C]
```

## Rationale（理由）

- 空树全零易于识别，且与合法哈希碰撞概率可忽略。
- 单叶不再包装可减少无意义计算。
- 奇数叶复制最后叶子是成熟 Merkle 树惯例，实现简单。

## Consequences（影响）

- 所有哈希树实现必须共享同一边界规则。
- 测试应分别覆盖 0、1、2、3 个叶子的根计算。

## Conception Relationship（与构想关系）

- 补充 conception 中哈希树结构未明确的边界处理。
- 不改变各树使用的叶子和分支哈希算法。
