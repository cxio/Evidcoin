# 转换指令（Conversion Instructions）

## 来源追溯

- `docs/conception/Instruction/8.转换指令.md` —— opcode `[67-79]` 逐条定义。
- `DEC-0001` —— Int/BigInt/Bytes 编码（大端、定宽 8 字节、math/big）。
- `DEC-0502` —— Float profile（`FLOAT` 结果不得 NaN/Inf）。

## 概述

- **opcode 区间：** `[67-79]`，13 个（含 1 个未用保留位 78）。
- **职责：** 将数据转换为不同类型与值（不仅类型变化，底层值也可能改变）。
- **设计：** 安全考虑**不提供**转换到脚本类型（`Script`）；基本类型间可互转，与复合类型仅部分可互转。
- **前置：** `0.Base-Constraints.md`。

## 规格正文

| opcode | 指令 | 目标 | 关键规则 |
|--------|------|------|----------|
| 67 | `BOOL` | Bool | nil/0/""/空 → false；其余 → true。测非空：`SIZE BOOL`。 |
| 68 | `BYTE` | Byte | nil→0；bool→0/1；Rune/Int/BigInt `<256` 正常否则出错；Float 取整后同。不支持与字符串互转。 |
| 69 | `RUNE` | Rune | nil→0；bool→0/1；Byte 直转；Int/BigInt `<=0x10FFFF` 否则出错；Float 取整后同。不支持与字符串互转。 |
| 70 | `INT` | Int(int64) | nil→0；bool→0/1；Byte/Rune 直转；BigInt `<=1<<63-1` 否则出错；Float 截断小数。便捷：Time→Unix 毫秒；String 按 Go 字面（十/二/八/十六进制、`_` 分隔，strconv）。 |
| 71 | `BIGINT` | BigInt | nil→0；bool→0/1；Byte/Rune/Int 直转。便捷：字节序列按大端（math/big）。 |
| 72 | `FLOAT` | Float | nil→0.0；bool→0.0/1.0；Byte/Rune/Int 直转。便捷：String 合法浮点/科学计数。结果须符合 DEC-0502 profile。 |
| 73 | `STRING(1){}` | String | 附参=进制(2-36，方括号，整数用)或浮点格式(`b/e/E/f/g/G/x/X`，花括号，浮点用)；`STRING(1){}` 语法记号区分格式标识（非关联数据，最小格式字符 `E`=69 与进制区间不冲突）。nil→""；bool→"true"/"false"；Byte 视 UTF-8 字节；Rune 视码点（合法字符或 `\uhhhh`/`\Uhhhhhhhh`）；Int/BigInt 按进制；Float 按格式。便捷：字节序列/符文序列按 UTF-8。 |
| 74 | `BYTES` | Bytes | nil→空切片；Byte→单字节切片；Rune→UTF-8；Int→大端固定 8 字节；BigInt→大端不定长。便捷：String/符文序列→UTF-8；Script→克隆源字节并类型转换。安全：**不支持字节序列转 Script**。 |
| 75 | `RUNES` | []Rune | nil→空切片；Rune→单符文切片；String→UTF-8 解码为 `[]rune`；字节序列→UTF-8 解码（无效码→`\uFFFD`）。 |
| 76 | `TIME` | Time | Int→Unix 毫秒；String→RFC3339；nil→零时（`1970-01-01T00:00:00.000Z`）。 |
| 77 | `REGEXP` | RegExp | 实参=字符串；仅支持从合法字符串构造（RE2）。 |
| 78 | （未用） | — | 保留，不分配。 |
| 79 | `ANYS(1){}` | []any↔[]T | 附参=转换标识（除 0 外即对应值指令码值，支持花括号写类型名）：0→`[]any`；1/2→`[]Bool`；3→`[]Byte`(同 Bytes)；4→`[]Rune`；5→`[]Int`；6→`[]*big.Int`；7→`[]Float`；8/9→`[]String`。实参=目标切片或 nil（nil 可转任意空切片）；`[]any` 成员自动转目标类型。 |

## 边界与限制

- 不提供任何到 `Script` 的转换（含字节序列）。
- 越界数值（Byte/Rune/Int 上限）转换出错。
- `STRING` 的进制/浮点格式标识互斥，分别用方括号/花括号。

## 对 Plan 的约束

1. 实现 13 指令的逐类型转换分支与越界出错；编码引用 DEC-0001/0502。
2. `STRING(1){}` 解析方括号进制 vs 花括号格式（语法记号非关联数据）。
3. `ANYS` 标识复用值指令码值；nil→空切片、`[]any`↔`[]T` 双向。
