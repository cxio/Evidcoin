# 工具指令（Tool Instructions）

## 来源追溯

- `docs/conception/Instruction/14.工具指令.md` —— opcode `[138-163]` 逐条定义、保留区。
- `DEC-0502` —— 浮点比较 `CMPFLO`、数值序列 profile。
- `DEC-0503`/`DEC-0505` —— `EVAL` 前期禁用、`SHELL` 公共节点忽略、确定性随机。
- `DEC-0504` —— `MAP`/`FILTER`/`EVAL` 迭代与子脚本成本计入。

## 概述

- **opcode 区间：** `[138-163]`，26 个（含未用 148-151、保留区 156-163 共 8 个量子安全保留位）。
- **职责：** 基础常用功能性指令，外加量子安全保留区。
- **前置：** `0.Base-Constraints.md`。

## 规格正文

| opcode | 指令 | 附参/实参 | 返回 | 规格 |
|--------|------|-----------|------|------|
| 138 | `EVAL` | 实参=Script | 一个切片 | 执行脚本指令序列；独立执行域与外部隔绝，仅内部数据栈遗留项作切片返回调用层（通关状态与调用层无关）；实参仅能由 `CODE`/`SCRIPT` 创建。**前期禁用**〔DEC-0505〕，公共路径触达即 `ScriptError`。 |
| 139 | `COPY` | 实参=一个切片 | 新切片 | 成员浅复制到新空间。 |
| 140 | `DCOPY` | 实参=一个切片 | 全新切片 | 成员递归深复制（子切片/any 成员递进）。 |
| 141 | `KEYVAL(1)` | 附参=切取类型(0=键值,1=键,2=值)；实参=字典 | 1~2 切片（自动展开） | 字典键值切取；返回两切片时成员一一对应。例：`@KEYVAL`。 |
| 142 | `MATCH(1){}` | 附参=匹配方式(`_`/g/G/f/S)；实参 1=目标(String/Bytes)、2=正则(*RegExp) | Bool/单值/切片 | 正则匹配，按目标类型自动选 String/Bytes 函数。`_`=Match(Bool)、`g`=全部完整、`G`=全部含捕获组(二维切片)、`f`=首个、`S`=首个含捕获组。无子匹配求全部用 `g`（`G` 必返二维）。 |
| 143 | `SUBSTR(~)` | 附参=符文数量；实参 1=字符串、2=起始字符位置(从 0) | 子字符串 | 按字符计数截取 UTF-8 字符串；长度不足返回空串（出错逻辑）。静态附参定义字符数更安全。 |
| 144 | `REPLACE(1)` | 附参=替换次数(0=全部)；实参 1=目标串、2=匹配式(子串/正则)、3=替换串 | 新字符串 | 字符串替换；正则匹配时替换串可含特殊标识。 |
| 145 | `RANDOM` | 实参 1=种子(32B)、2=上限(不含,Int/Float) | 非负随机数(同实参类型) | 确定性随机数，math/rand/v2 ChaCha8。 |
| 146 | `SLRAND` | 实参 1=种子(32B)、2=切片 | 新切片 | 确定性成员乱序重排，math/rand/v2 ChaCha8。 |
| 147 | `CMPFLO(1)` | 附参=类型(0=`==`,-1=`<=`,1=`>=`)；实参 1/2=待比较值、3=误差 | Bool | 浮点比较，差值不超误差视为相等；弥补比较指令浮点相等不足〔DEC-0502〕。 |
| 148-151 | （未用） | — | — | 保留，不分配。 |
| 152 | `RANGE(1)` | 附参=序列长度；实参 1=起始(Int/Float)、2=步进 | 数值切片 | 创建数值序列；类型以实参 1 为基准；附参 0 创建空切片（实参 1 仅表类型）；附参 1 字节限小序列（性能/安全），大集合用 `MERGE` 合并。例：`{10}{1}RANGE[5]`→`[10,11,12,13,14]`。 |
| 153 | `MAP{}(~)` | 附参=子块长；实参不定(首=目标集，余=私有栈初始成员) | 一个切片 | 映射迭代；子块独立脚本域（私有数据栈/实参区/全局变量），各迭代间共享；循环变量 `$Value`/`$Index`/`$Key`/`$Slice`/`$Dict`/`$Size`；返回 nil 被忽略（兼具筛选）；字典按插入序迭代。用 `RETURN` 返回值。 |
| 154 | `FILTER{}(~)` | 同 `MAP` | 切片或字典 | 成员过滤；返回真则选取（不影响原集）；返回值类型同目标集（切片→切片、字典→字典）；语法同 `MAP`。 |
| 155 | `SHELL{}(~)` | 附参=内容长度；实参=字节序列 | 无 | 独立环境执行 Shell；首行 Shebang 标记解释器；**公共验证节点忽略（但正常消费实参，非错误）**，仅私有域节点使用（通常花费者公钥识别）；无返回值不影响共识〔DEC-0505〕。**非禁用指令**。 |
| 156-163 | （保留区） | — | — | 量子安全等未来基础支持，共 8 个，不分配。 |

## 边界与限制

- `EVAL` 前期禁用，公共路径触达即失败；testnet/devnet 实现。
- `SHELL` 公共节点忽略（消费实参不报错），私有节点执行；无返回值。
- `RANDOM`/`SLRAND` 必须确定性（种子驱动，ChaCha8），不得用系统随机源。
- `RANGE` 附参 1 字节限小序列。

## 待决问题

- 保留区（156-163）量子安全指令的具体定义留待未来。

## 对 Plan 的约束

1. `EVAL` 主网禁用、testnet/devnet 实现；隔离执行域、仅栈遗留返回。
2. `RANDOM`/`SLRAND` 用 math/rand/v2 ChaCha8 确定性实现。
3. `MAP`/`FILTER` 独立脚本域 + 迭代间共享、`RETURN` 语义、nil 忽略；`SHELL` 公共忽略私有执行。
4. `MATCH`/`CMPFLO`/`SUBSTR`/`REPLACE`/`KEYVAL`/`COPY`/`DCOPY`/`RANGE` 按上表实现。
