# 流程控制（Flow Control）

## 来源追溯

- `docs/conception/Instruction/7.流程控制.md` —— opcode `[58-66]` 逐条定义、IF/ELSE 平级规则、循环说明。
- `DEC-0501` —— 子语句块作为关联数据按附参长度编码。
- `DEC-0504` —— `EACH` 迭代按实际次数计入成本。

## 概述

- **opcode 区间：** `[58-66]`，9 个。
- **职责：** 控制脚本执行路径；子语句块即关联数据。本类指令无返回值。
- **前置：** `0.Base-Constraints.md`。

## 规格正文

| opcode | 指令 | 附参/实参 | 规格 |
|--------|------|-----------|------|
| 58 | `IF{}(~)` | 附参=子块长度；实参=布尔值 | 实参 true 则执行子块；同层级后来的 IF 覆盖先前 IF 状态。 |
| 59 | `ELSE{}(~)` | 附参=子块长度；实参无 | 本层级 IF 为假则执行；匹配最近一个 IF（不需紧邻）；同层 IF/ELSE 共享状态变量；连续 ELSE 仅第一个有效。平级不可嵌套，父子级正常嵌套。 |
| 60 | `SWITCH{}(~)` | 附参=块长；实参 1=标的值、2=CASE 分支值列表(长度=CASE 数) | 创建 switch 块；标的与 CASE 值相等比较（任意可比较类型）；标的为 true 可模拟 if/elseif/else。 |
| 61 | `CASE{}(~)` | 附参=子块长；实参无（预先提取，按位置顺序对比） | 真则执行子块；只有最先匹配的 CASE 执行，之后 SWITCH 结束；块内可 `BREAK`。 |
| 62 | `DEFAULT{}(~)` | 附参=子块长；实参无 | 所有 CASE 为假时执行；作为最后一个块，可选。 |
| 63 | `EACH{}(~)` | 附参=子块长；实参=目标集(切片/字典) | 对成员逐一迭代执行子块（无私有数据栈，区别于 MAP/FILTER）；循环变量 `$Value`/`$Index`/`$Key`/`$Slice`/`$Dict`/`$Size`；中断用 `BREAK` 非 `RETURN`。 |
| 64 | `CONTINUE` | 实参=布尔值(可选) | 终止当前 EACH 迭代、开始下一次；有实参则 true 执行，否则直接执行。 |
| 65 | `BREAK` | 实参=布尔值(可选) | 退出 EACH 循环或 SWITCH 分支区；有实参则 true 执行，否则直接执行。 |
| 66 | `BLOCK{}(~)` | 附参=子块长；实参无 | 创建子块（局部域/分离指令序列范围）；用于规划局部变量或 `SOURCE` 提取局部片段。 |

> **关于循环：** 无无限循环，用 `EACH` 表达有限循环；块内支持 `BREAK` 而非 `RETURN`〔conception〕。

## 边界与限制

- IF/ELSE 平级不可嵌套（`IF{} IF{} ELSE{} ELSE{}` 第二个 ELSE 非法）；父子级嵌套合法。
- `SWITCH` 标的值与 CASE 值列表一次性给出。
- `EACH` 按实际迭代次数与处理数据量计入成本〔DEC-0504〕。

## 待决问题

- 无。

## 对 Plan 的约束

1. 子块按附参长度作为关联数据解析（DEC-0501）。
2. IF/ELSE 同层状态变量与覆盖语义、平级不嵌套校验。
3. `EACH`/`SWITCH` 循环变量与分支预取实现；`BREAK`/`CONTINUE` 限循环、`RETURN` 不用于循环。
