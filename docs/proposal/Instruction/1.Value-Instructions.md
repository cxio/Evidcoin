# 值指令（Value Instructions）

## 来源追溯

- `docs/conception/Instruction/1.值指令.md` —— opcode `[0-18]` 逐条定义。
- `docs/conception/Instruction/0.基本约束.md` —— 指令结构、说明格式。
- `DEC-0001` —— ULEB128/定宽大端/BigInt（`slen||magnitude`）/Int 编码。
- `DEC-0501` —— 字节码编码、单引号字面量码点规则、源码非共识。
- `DEC-0502` —— Float binary64 profile（字面量不得 NaN/Inf）。

## 概述

- **opcode 区间：** `[0-18]`，19 个（含 2 个未用保留位 14-15）。
- **职责：** 作为具体值存在，执行时直接入栈或构造值。
- **前置：** `0.Base-Constraints.md`。

## 规格正文

| opcode | 指令 | 类型 | 规格 |
|--------|------|------|------|
| 0 | `NIL` | Nil | 通用 nil；opcode 本身表达该值，无附参/数据。 |
| 1 | `TRUE` | Bool | opcode 直接表达 `true`。 |
| 2 | `FALSE` | Bool | opcode 直接表达 `false`。 |
| 3 | `''`（byte） | Byte | 单字节 `[0,255]`，uint8 别名；码点 `<=0xff` 的单引号字面量编译至此〔DEC-0501〕。 |
| 4 | `''`（rune） | Rune | Unicode 码点 `[0,0x10FFFF]`，4 字节（uint32）；仅码点 `>0xff` 编译至此〔DEC-0501〕。 |
| 5 | `{}`（int） | Int | int64；opcode 后直接跟随变长整数字节序列（无附参，varint 自含长度，省 1 字节）〔DEC-0001〕。 |
| 6 | `{}(1)`（bigint） | BigInt | 附参 1 字节：bit7 符号（0 正 1 负）+ 低 7 位字节数（0-127）；数据为绝对值大端；编码即 `BigIntBytes = slen \|\| magnitude`〔DEC-0001〕。最多 127 字节。 |
| 7 | `{}`（float） | Float | float64，8 字节大端 bit pattern；字面量不得 NaN/Inf；需含小数点区分整数〔DEC-0502〕。 |
| 8 | `""(~)`（string） | String | 附参变长整数 = 字节数；数据 UTF-8；支持 Go 风格转义与反引号原始串。 |
| 9 | `{...}(~)`（value set） | Values | 附参 = 成员序列总字节长；成员同类型或可提升（`Byte=>Rune=>Int=>BigInt`、`Byte=>Rune=>Int=>Float`；Float/BigInt/String 不可再提升）；提升发生在运行时。 |
| 10 | `DATA{}(~)` | Bytes | 附参变长整数 = 字节数；数据十六进制（无 `0x`）；支持显式长度，空位补零。 |
| 11 | `/.../(1)`（regexp） | RegExp | 附参 1 字节 = 内容字节数（`<256`）；RE2 语义；最长 255 字节。 |
| 12 | `DATE{}` | Time | 数据为 UNIX 毫秒（有符号变长）；花括号写 RFC3339；支持方括号写毫秒时间戳。 |
| 13 | `DICT` | Dict | 有序 `map[string]any`；实参 1=键序列(`[]string`)，实参 2=值序列(`[]any`)；长度不一时键多则补 nil、值多则忽略；唯一需实参构造值的值指令。 |
| 14-15 | （未用） | — | 保留，不分配。 |
| 16 | `CODE{}(~)` | Script | 附参 = 序列长度；数据为已编译指令序列；**字面值，不执行**（配合 `EVAL` 或第三方扩展）。 |
| 17 | `SCRIPT(~,48,~)` | Script | 附参：年度(varint)、TxID(48B)、输出序位(varint)；引入交易输出脚本。**前期禁用**〔DEC-0505〕；支持验证上下文携带〔DEC-0503〕。 |
| 18 | `VALUE(1){}` | Any | 附参 1 字节 = 值索引；花括号为别名（非关联数据）；通用取值（与 ENV 有重叠）。**前期禁用**〔DEC-0505〕。 |

## 边界与限制

- 值指令产生运行时值，不代表自动具备规范化链上编码（编码规则见第 01 章）。
- `CODE`/`SCRIPT` 入栈后不执行。
- RegExp 必须 RE2，无回溯爆炸风险。
- `DATE`/Time 不得在公共验证隐式使用本地当前时间；字面值固定为确定性值。
- `SCRIPT`(17)、`VALUE`(18) 当前禁用，不进入主网有效脚本。

## 待决问题

- 无（编码已由 DEC-0001/0501/0502 冻结）；`VALUE` 可取值表与 `ENV` 边界在解禁前不固定，列入第 10 章 C-7 范畴。

## 对 Plan 的约束

1. 值指令解析按上表 opcode、附参、数据 schema 实现；Int/BigInt/Float/String 编码严格引用第 01 章/DEC-0502。
2. 单引号字面量编译按码点 `0xff` 阈值区分 Byte/Rune。
3. `SCRIPT`/`VALUE` 主网禁用，testnet/devnet 实现。
4. RegExp 拒绝非 RE2 特性。
