# 系统指令（System Instructions）

## 来源追溯

- `docs/conception/Instruction/15.系统指令.md` —— opcode `[164-169]` 逐条定义。
- `DEC-0505` —— `SYS_TIME` 仅 END 后可用、`SYS_CHKPASS` 通关语义、签名验证标注。
- `DEC-0503` —— `SYS_AWARD` 链段检查的确定性。
- `docs/conception/4.激励机制.md`、`docs/conception/附.交易.md` —— 兑奖槽、签名验证逻辑。

## 概述

- **opcode 区间：** `[164-169]`，6 个（含未用 167-168）。前缀 `SYS_`。
- **职责：** 少量系统级功能指令。
- **前置：** `0.Base-Constraints.md`。

## 规格正文

| opcode | 指令 | 附参/实参 | 返回 | 规格 |
|--------|------|-----------|------|------|
| 164 | `SYS_TIME(1){}` | 附参=条目标识 | 目标值(数值统一 Int) | 全局时间取值（客户端真实当前时间）。条目：默认(Time)、`Stamp`、`Year`、`Month`、`YearDay`、`Day`、`WeekDay`、`Hour`、`Minute`、`Second`、`Millisecond`、`Microsecond`。**节点时间不确定，禁用于共识**：只能在明确 `END` 或隐性 END(`INPUT`) 之后执行，否则脚本错误失败（特例）〔DEC-0505〕。 |
| 165 | `SYS_AWARD(1,4)` | 附参 1=脚本所在输出序位、2=区块高度(4B)；实参无 | Bool | 兑奖验算：核查区块高度与兑奖槽确认数，输出可兑奖比例(0/50/100)。**仅可用于 Coinbase 交易输出脚本**，否则失败。激活系统币金平衡再计算（检索接收者金额×比例向下取整）；100% 可跳过再计算；币金平衡无问题时即便 0 比例也返回真。检查附参 2 之后链段(+31~48)〔DEC-0503〕。 |
| 166 | `SYS_CHKPASS` | 实参无（参数从环境提取，特例） | 无 | 系统验证：内置地址核实 + 签名验证（单签/多签），**也是通关指令**（如 PASS），验证失败退出。币金/凭信不同逻辑但都由本指令启动（币金提取数量、凭信一次性消费）；验证类别从输出项配置字节低四位(1=币金,2=凭信)。声明：`SYS_CHKPASS(接收者,验证类别,签名类型,授权标记,[]签名,[]公钥,[]初级哈希)`，签名类型及后续实参从环境提取（特例，强化隐私）。可置于 GOTO/EMBED/SCRIPT 外部脚本。验证成功在系统层标注结果供 `SIGNED` 查询；先核实公钥哈希再验签〔DEC-0505〕。 |
| 167-168 | （未用） | — | — | 保留，不分配。 |
| 169 | `SYS_NULL` | — | — | 源码零点标识：在当前位置设 NULL 点作为 `SOURCE` 片段提取起点；NULL 点本身不被提取。可用于解锁脚本段提供"解锁↔锁定"衔接灵活性（特例）。**可突破解锁段限制**（见第 10 章解锁段说明）。 |

## 边界与限制

- `SYS_TIME` 仅 `END`/隐性 END 后可用，END 前使用脚本错误失败。
- `SYS_AWARD` 仅 Coinbase 交易输出脚本，否则失败。
- `SYS_CHKPASS` 是通关指令，失败即退出；签名相关实参从环境提取（剥离解锁数据中签名，不参与 TxID 计算，便于数据剪枝）。
- `SYS_NULL` 标记的 NULL 点不参与源码提取。

## 对 Plan 的约束

1. `SYS_TIME` 仅 END 后可用，否则 `ScriptError`；数值统一 Int。
2. `SYS_AWARD` 限 Coinbase、激活币金平衡再计算、检查后续链段（+31~48）。
3. `SYS_CHKPASS` 作为通关指令实现地址核实 + 单/多签验证、环境提取参数、系统层标注；`SYS_NULL` 双游标 NULL 点（配合 `SOURCE`）。
