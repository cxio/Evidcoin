# 截取指令（Capture Instructions）

## 来源追溯

- `docs/conception/Instruction/2.截取指令.md` —— opcode `[19-23]` 逐条定义。
- `docs/conception/Instruction/0.基本约束.md` —— 实参区/局部域语义。
- `DEC-0501` —— 实参区 FIFO、参数消费顺序。

## 概述

- **opcode 区间：** `[19-23]`，5 个。
- **职责：** 拦截指令返回值、从目标位置取值、或赋值到特定区域；取值直接放入实参区（而非自动入栈）。
- **前置：** `0.Base-Constraints.md`。

## 规格正文

| opcode | 指令 | 作用 | 规格 |
|--------|------|------|------|
| 19 | `@` | 实参捕获 | 拦截后一指令返回值放入实参区。例：`@PEEKS[2]`、`@{1234}`。 |
| 20 | `$` | 局域存值 | 截取后一指令返回值添加到当前局部域（静态堆叠，只添加，容量 128，块级私有）。例：`$TOP`、`$POPS[3]`、`${100}`、`$SHIFT[3]`。 |
| 21 | `$(1)` | 局域取值（引用） | 附参 = 成员位置下标 `[-128,127]`（负数从末尾）；引用局部域值放入实参区。例：`$[0]`、`$[-1]`；可支持名称引用 `${POP}`（有重名覆盖问题）。 |
| 22 | `$X(1)` | 循环域变量引用 | 用于循环体内，可跨语法块层级；引用值放入实参区；附参标识 `[0-3]`：`$Value`[0]、`$Index`/`$Key`[1]、`$Slice`/`$Dict`[2]、`$Size`[3]；名称大小写敏感，前置 `$`。 |
| 23 | `~` | 实参直取 | 指示后一指令实参从数据栈直接提取（跳过实参区）；与 `@`/`$` 同用时应位于其后、目标指令之前。例：`~EQUAL`、`@~EQUAL`、`$~EQUAL`。 |

> **小结：** 除局域存值（`$`）和实参直取（`~`）外，另 3 个（`@`/`$[n]`/`$X`）均为取值，结果统一放入实参区〔conception〕。

## 边界与限制

- 截取指令用特殊符号表达，与目标指令可无空格分隔（友好书写）。
- 局部域跨块不可互访，仅同级共享。
- `$X` 循环变量与普通局域不同，可跨块层级（限循环体内）。

## 待决问题

- 无（语义已由 conception + DEC-0501 明确）。

## 对 Plan 的约束

1. 实现实参区 FIFO 与局部域堆叠（容量 128、负下标、名称引用与重名覆盖）。
2. `~` 仅改取参来源，不改返回去向；与 `@`/`$` 组合顺序须校验。
3. `$X` 循环变量绑定到当前迭代上下文（`$Value`/`$Index`/`$Key`/`$Slice`/`$Dict`/`$Size`）。
