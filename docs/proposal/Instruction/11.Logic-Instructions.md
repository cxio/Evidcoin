# 逻辑指令（Logic Instructions）

## 来源追溯

- `docs/conception/Instruction/11.逻辑指令.md` —— opcode `[112-115]` 逐条定义。
- `docs/proposal/Instruction/8.Conversion-Instructions.md` —— `ANYS{Bool}` 集合转换前置。

## 概述

- **opcode 区间：** `[112-115]`，4 个。
- **职责：** 实参为布尔类型，返回布尔值的逻辑运算。
- **前置：** `0.Base-Constraints.md`。

## 规格正文

| opcode | 指令 | 实参 | 返回 | 规格 |
|--------|------|------|------|------|
| 112 | `BOTH` | 1/2=布尔值 | Bool | 逻辑 AND，两值都为真。例：`BOTH PASS`。 |
| 113 | `EITHER` | 1/2=布尔值 | Bool | 逻辑 OR，两者任一为真。例：`EITHER PASS`。 |
| 114 | `EVERY` | 布尔值集合 | Bool | 逻辑 AND，全部成员为真；成员可为 Bool 或其 any 封装，否则先 `ANYS{Bool}`；空集返回 `true`。例：`SHIFT[3] ANYS[1] EVERY`。 |
| 115 | `SOME(1)` | 附参=n(最低为真数量)；实参=布尔值集合 | Bool | 逻辑 OR，至少 n 个为真；成员类型同 `EVERY`；`SOME[0]` 无条件真，`SOME[1]` 常用，空集 `SOME[1]` 返回 `false`。 |

## 边界与限制

- `EVERY`/`SOME` 集合成员须为 Bool 或可 `ANYS{Bool}` 转换的 any 封装。
- 空集语义：`EVERY` → true，`SOME[1]` → false（`SOME[0]` 恒 true）。

## 待决问题

- 无。

## 对 Plan 的约束

1. 实现 4 指令；`BOTH`/`EITHER` 双实参、`EVERY`/`SOME` 集合实参。
2. 集合成员类型校验，必要时要求 `ANYS{Bool}` 前置。
3. 空集与 `SOME[n]` 边界语义按 conception。
