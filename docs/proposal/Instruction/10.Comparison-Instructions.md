# 比较指令（Comparison Instructions）

## 来源追溯

- `docs/conception/Instruction/10.比较指令.md` —— opcode `[104-111]` 逐条定义。
- `DEC-0502` —— 浮点相等比较与异常浮点值判定。

## 概述

- **opcode 区间：** `[104-111]`，8 个。
- **职责：** 两个或多个值比较，返回布尔值。
- **注意：** 相等比较也适用浮点数但应慎用，可改用工具指令 `CMPFLO`〔conception〕。
- **前置：** `0.Base-Constraints.md`。

## 规格正文

| opcode | 指令 | 实参 | 返回 | 规格 |
|--------|------|------|------|------|
| 104 | `EQUAL` | 1/2=可比较值 | Bool | `a==b`；特别支持字节序列从左到右逐字节比较；Bool 仅适用 `EQUAL`/`NEQUAL`。 |
| 105 | `NEQUAL` | 同上 | Bool | `a!=b`。 |
| 106 | `LT` | 同上 | Bool | `a<b`。 |
| 107 | `LTE` | 同上 | Bool | `a<=b`。 |
| 108 | `GT` | 同上 | Bool | `a>b`。 |
| 109 | `GTE` | 同上 | Bool | `a>=b`。 |
| 110 | `ISEFV(1)` | 附参=标识(0=NaN,1=+Inf,2=-Inf)；实参=任意值 | Bool | 判断异常浮点值；浮点计算中可能出现这些特殊值需判断〔DEC-0502〕。 |
| 111 | `WITHIN` | 1=待比较值、2=范围(2 成员切片) | Bool | `min<=x<max`；支持 Byte/Rune/Int/BigInt/Float；浮点下边界相等判断可能不精确。例：`ENV{Height} {0,240} WITHIN`。 |

## 边界与限制

- Bool 仅 `EQUAL`/`NEQUAL` 可比；其余顺序比较用于可排序类型。
- 浮点相等/边界相等不精确，精确浮点比较用 `CMPFLO`（第 14 章）。
- 字节序列逐字节比较。

## 待决问题

- 无。

## 对 Plan 的约束

1. 实现 8 指令；字节序列逐字节、Bool 限相等。
2. `ISEFV` 按 DEC-0502 异常浮点值标识判定（NaN/±Inf）。
3. `WITHIN` 半开区间 `[min,max)`，浮点边界相等用误差容忍由调用方注意。
