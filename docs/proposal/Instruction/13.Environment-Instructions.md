# 环境指令（Environment Instructions）

## 来源追溯

- `docs/conception/Instruction/13.环境指令.md` —— opcode `[128-137]` 逐条定义、五层嵌套环境。
- `DEC-0503` —— 环境/输出引用边界、`INOUT` 验证上下文优先、确定性环境值。
- `DEC-0505` —— `INOUT` 前期禁用、`SIGNED`/通关状态校验域语义。
- `docs/conception/6.脚本系统.md` —— `SYS_NULL` 点与源码提取游标。

## 概述

- **opcode 区间：** `[128-137]`，10 个（含 1 个未用保留位 132）。
- **职责：** 取嵌套环境（`系统域 > 交易域 > 校验域 > 脚本域 > 块域`）变量。多数无实参，`SETVAR` 例外。
- **前置：** `0.Base-Constraints.md`。数据栈/实参区属脚本域，可嵌套。

## 规格正文

| opcode | 指令 | 附参/实参 | 规格 |
|--------|------|-----------|------|
| 128 | `ENV(1){}` | 附参=目标标识 | 环境变量取值。系统域：`BlockTime`(当前待创建区块时间戳)、`Height`(=`TipHeight+1`)、`TipHeight`；交易域：`TxID`、`TxTime`；校验域：`Passed`、`InGoto`、`InEmbed`、`InScript`、`InCode`、`Gotos`(GOTO 深度)、`Source`(全源码含解锁)、`Source0`(锁定源码)、`Source1`~`Source9`(各 EMBED 源码)。环境值须确定性〔DEC-0503〕。 |
| 129 | `IN(1){}` | 附参=目标标识 | 输入项取值（校验域，站在锁定脚本源未来被花费视角）。`Timestamp`/`TxID`/`Height`/`Amount`/`Receiver`/`Remarks`/`Locked`/`Unlock`/`Source`/`Index`；凭信特有：`Creator`/`Title`/`Description`/`Attachment`。`Locked`/`Unlock`/`Source` 便于模式验证。 |
| 130 | `OUT(~,1){}` | 附参 1=输出序位(起 0)、2=目标标识 | 输出项取值（交易域，当前验证交易输出集，锁定脚本可约束未来花费者如遗嘱）。`Amount`/`Receiver`/`Remarks`/`Creator`/`Title`/`Description`/`Content`/`Attachment`/`Locked`。例：`OUT{0,Amount}`。 |
| 131 | `INOUT(~,1){}` | 附参 1=输出序位、2=目标标识 | 源输出项取值（输入项来源交易输出集兄弟条目）。条目同 `OUT`。支持用户提供输出项数据与验证上下文（避免实时网络查询）〔DEC-0503〕。**前期禁用**〔DEC-0505〕，公共路径触达即 `ScriptError`。 |
| 132 | （未用） | — | 保留，不分配。 |
| 133 | `XFROM(1){}` | 附参=目标标识 | 获取源交易信息（交易域）。**仅在 `GOTO`/`EMBED` 目标脚本中可用**。`InSize`/`InAmount`/`OutSize`/`OutAmount`/`Account`/`Amount`/`PayType`/`Locked`/`Source`(Locked 从开头到跳转点)/`Timestamp`。源交易=花费输出时当前正在验证的交易。 |
| 134 | `SIGNED(1)` | 附参=目标序位 | 签名序位核实（校验域，GOTO 目标可见）。检查多签清单中该序位公钥是否已参与签名且验证合法（单签仅 0 合法）；返回 Bool。`FN_CHECKSIG`/`FN_MCHECKSIG`/`SYS_CHKPASS` 验证后在系统层标注状态（`SYS_CHKPASS` 仅成功时标注）〔DEC-0505〕。例：`SIGNED[0] SIGNED[1] SIGNED[2] SHIFT[3] SOME[2] PASS`。 |
| 135 | `VAR(1)` | 附参=变量位置 `[0-255]` | 全局变量取值（脚本域）。变量逻辑可被覆盖；**不跨 GOTO**，但 EMBED 共享环境相互影响。例：`@VAR[0]`、`VAR[10]`。 |
| 136 | `SETVAR(1)` | 附参=变量位置 `[0-255]`；实参=任意单值 | 全局变量赋值（脚本域），配合 `VAR`。例：`{123} SETVAR[1]`。 |
| 137 | `SOURCE(1)` | 附参=标识值（高位表跨块域） | 脚本源码（编译后指令序列）提取，返回 Bytes 副本。块内（前阶含 SOURCE、后阶不含）：`0x00`当前块完整、`0x01`前阶已执行、`0x02`从最近 NULL 点起、`0x04`后续到块末。跨块域：`0x80/0x81/0x82/0x84` 对应整脚本含解锁。NULL 点由 `SYS_NULL` 标记且任何情况都不含；不支持以 NULL 点为终点的后阶提取。实现需块域局部与脚本全局两个 NULL 游标。 |

## 边界与限制

- `VAR`/`SETVAR`/`SOURCE` 属脚本域，不跨 GOTO；EMBED 共享。
- `XFROM` 仅 GOTO/EMBED 目标脚本可用。
- `INOUT` 前期禁用，公共路径触达即失败。
- 重要环境信息（`ENV`/`IN`/`OUT`/`INOUT` 部分成员）应对中间件开放以感知系统状态〔conception 实现参考〕。

## 待决问题

- `ENV`/`IN`/`OUT` 条目名称非全面，详以实现为准〔conception〕。

## 对 Plan 的约束

1. 实现五层环境域与取值；环境值确定性（无本机时间/随机）。
2. `INOUT` 主网禁用、testnet/devnet 实现；`INOUT` 支持验证上下文优先。
3. `SOURCE` 双 NULL 游标、NULL 点不含、不支持以 NULL 为终点的后阶提取；`SIGNED` 读取系统层签名验证标注。
