# 结果指令（Result Instructions）

## 来源追溯

- `docs/conception/Instruction/6.结果指令.md` —— opcode `[51-57]` 逐条定义。
- `DEC-0505` —— 执行状态机、通关状态语义（`PASS`/`CHECK` 覆盖、`PASS false` 立即失败、`END`/`INPUT` 隐式结束）。
- `DEC-0503` —— `GOTO`/`EMBED` 目标可验证性、验证上下文优先。
- `DEC-0504` —— `GOTO`/`EMBED` 计数与成本归调用方。

## 概述

- **opcode 区间：** `[51-57]`，7 个。
- **职责：** 产生决定性结果——通关检查、跳转、函数返回、脚本结束。
- **前置：** `0.Base-Constraints.md`。初始通关状态为 `true`〔DEC-0505〕。

## 规格正文

| opcode | 指令 | 附参/实参 | 规格 |
|--------|------|-----------|------|
| 51 | `PASS` | 实参=布尔值 | 写入通关状态；`true` 继续；`false` 立即 `VerifyFail` 结束。多 PASS 类似 "And"〔DEC-0505〕。 |
| 52 | `CHECK` | 实参=布尔值 | 写入通关状态但不退出；后写覆盖前值（取最后一个）；类似 "Or"（但不同）〔DEC-0505〕。 |
| 53 | `GOTO(~,48,~)` | 附参：年度、TxID(48B)、输出序位；实参不定 | 跳转到目标输出脚本；实参传为新脚本数据栈初始内容；新脚本有独立环境（数据栈/实参区/全局域）但延续当前校验与通关状态；私有残留退出后丢弃；目标可含 GOTO/EMBED。回馈仅限通关状态（不返回栈残留，防注入）。目标缺失/不可验证→`ScriptError`〔DEC-0503〕；先计数再解析、成本归调用方〔DEC-0504〕。 |
| 54 | `EMBED(~,48,~)` | 附参：年度、TxID(48B)、输出序位；实参无 | 嵌入目标输出脚本，**共享当前脚本域**（数据栈/实参区/全局域），直接执行并向当前栈添加内容。目标可验证性/计数/成本同 `GOTO`〔DEC-0503/0504〕。 |
| 55 | `EXIT` | 实参=任意单值(可选) | 终止脚本退出；退出前检查通关状态；有实参则返回该值（可被系统处理），无则简单结束。可用于 IF 块内或顶层。 |
| 56 | `RETURN` | 实参=任意单值(可选) | 从函数子块退出并返回值；仅用于 `MAP{}`/`FILTER{}`，退出当前迭代；无实参返回 nil。 |
| 57 | `END` | — | 公共验证逻辑结束、脚本退出（以当前通关状态 `PassStop`）；仅公共验证节点有效，私有节点忽略并可继续私有路径。用于定向加密等"仅对特定方有意义"的场景〔DEC-0505〕。 |

## 边界与限制

- `PassStop(false)` 不等同 `PASS false` 的立即失败，但共识后果同为交易不合法〔DEC-0505〕。
- `GOTO`/`EMBED` 受跳转/嵌入次数与深度限制（见第 03/10 章：`GOTO` 次数 ≤2/深度 ≤3、`EMBED` 次数 ≤4/深度 ==0）。
- `END`/公共 `INPUT` 后私有路径不参与共识。

## 待决问题

- 无（语义由 DEC-0505 冻结）。

## 对 Plan 的约束

1. 实现通关状态：初始 `true`，`PASS`/`CHECK` 后写覆盖，`PASS false` 立即 `VerifyFail`。
2. `GOTO`（独立环境）与 `EMBED`（共享域）按语义实现；目标不可验证→`ScriptError`；先计数再解析、成本归调用方。
3. `END` 公共节点 `PassStop`、私有节点可继续；`RETURN` 限 `MAP`/`FILTER`。
